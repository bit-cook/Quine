# 什么是 Quine

一个 Quine 通常由两部分组成：

  • 代码部分 (Code) — 程序的逻辑指令。
  • 数据部分 (Data) — 代码部分的文本表示（通常是字符串）。

执行时，程序用数据部分重构代码部分，再原样输出数据部分本身，于是得到与自身逐字节相同的输出。

程序 = 数据 + 使用数据输出「数据 + 使用数据输出」

注意：读取自身源文件（如 cat "$0"）不算 Quine。真正的 Quine 不借助任何外部输入。

classic/quine.py
s='s=%r;print(s%%s)';print(s%s)
运行它，输出与源码完全相同。

# 背后的理论

克莱尼递归定理

Quine 的存在并非巧合，而是 Kleene 递归定理（不动点定理）的直接推论：在任何图灵完备的语言中，都存在一个程序能输出自身的源代码。

对角线论证

其证明思想源自康托尔/哥德尔的对角线法：构造一个“作用于自身描述”的程序，让它输出“被自身描述所指向的那个程序”。

自指悖论

Quine 与哲学上的自指（如说谎者悖论）同源，故名取自逻辑学家 Willard Van Orman Quine。

泛型构造（不动点）
设 template 是含占位符的程序模板，
则 quine = template % repr(template)

运行 quine：
  template 用 repr(template) 填回自身，
  输出恰好等于 template % repr(template)
  —— 即 quine 本身。
这正是 s='s=%r;print(s%%s)';print(s%s) 的工作原理。
